# PWM Duty Cycle Fader Example

This example shows how to configure Timer0 in Fast PWM mode on the ATmega32, enable output on channel A (pin OC0 / PB3), and sweep the duty cycle up and down.

## How to run
1. Start the simulation.
2. Click the **Plotter** tab on the Serial Monitor area.
3. Observe the sweeping duty cycle value plotted in real-time.
