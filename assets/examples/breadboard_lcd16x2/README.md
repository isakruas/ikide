# LCD 16x2 (HD44780 + I2C backpack)

Runs the standard 4-bit initialization through the PCF8574 backpack, then
prints `HELLO` on line 1 and `IKIDE` on line 2.

## On the breadboard

- Add the **LCD 16x2 I2C (HD44780)** device.

## Run

Run — the device card shows the two text lines. The I2C tab shows every
EN-pulsed nibble pair on the bus.
