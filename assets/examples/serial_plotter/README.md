# Serial Plotter Test

This example generates two simple and continuous numeric signals that rise and fall, transmitting them over UART. It is ideal for validating the operation of the **Serial Plotter** tab in the IDE.

## How to Run
1. Open this project/folder in IKIDE.
2. Start the simulation by pressing `Shift + S` (or selecting **Run -> Simulate** in the menu).
3. Open the **Serial Monitor** (View -> Serial Monitor).
4. Select the **Plotter** tab to see the waves generated graphically in real-time.
