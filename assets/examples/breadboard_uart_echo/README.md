# UART Echo

Prints a greeting, then echoes back every received byte.

## On the breadboard

- Nothing to wire; uses the on-chip USART.
- Optional: I2C/SPI not used here.

## Run

Run, open the **UART** tab: type in the Send box and watch your text echoed. (Or attach the **UART Loopback** device to echo without the program.)
