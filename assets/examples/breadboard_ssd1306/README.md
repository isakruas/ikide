# SSD1306 OLED

Initializes the display (horizontal addressing, full-screen window) and
streams a 1024-byte checkerboard frame over I2C.

## On the breadboard

- Add the **SSD1306 OLED 128x64** device.

## Run

Run — the 128×64 panel at the top of the Board tab fills with a fine
checkerboard. The I2C tab shows the command and data transactions.
