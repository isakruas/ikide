# Analog ADC Serial Plotter Example

This example shows how to configure the Analog-to-Digital Converter (ADC) of the ATmega32, read the raw values from ADC channel 0 and channel 1, and output them to the Serial Monitor in a format recognized by the Serial Plotter.

## How to run
1. Click the **Plotter** tab on the Serial Monitor area.
2. Start the simulation.
3. You will see two channels (`ch0` and `ch1`) dynamically updating in the plotter.
