# ADC Threshold

Reads a potentiometer on **ADC0**, lights an LED on **PB5** above mid-scale, and prints the value over UART.

## On the breadboard

- Add a **Potentiometer** (ADC channel 0).
- Add an **LED** on **PB5**.

## Run

Run, drag the potentiometer slider; the LED turns on past 512 and the UART tab shows the value.
